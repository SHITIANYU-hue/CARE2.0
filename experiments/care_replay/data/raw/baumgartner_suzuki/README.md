CARE 2.0 treats `MINLP1 optimization` and `MINLP2 optimization` as separate
real campaigns. Public candidate variables are precatalyst identity,
temperature, residence time, and precatalyst fraction. Reaction yield is
revealed only when replay selects a candidate.

The v2 external confirmation uses MINLP1 as the completed source and MINLP2 as
the target. MINLP2 outcomes are not loaded during C-N development selection.
