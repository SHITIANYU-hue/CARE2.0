# BH 语义标签匿名化 v2：完整结果与投稿含义

2026-10-20，WSL `/home/tangchao/projects/care2.0`。全部 20 次新生成、50 个校准种子、100 个留出种子均完成；独立统计与轨迹审计通过。

**本轮未支持“提供化学语义标签带来稳定的 AUC 优势”。** 主差值（有标签 − 匿名）为 **-0.260**，95% 交叉 bootstrap 区间 **[-1.781, +1.365]**。五个预定种子块中仅 3 块为正，未满足冻结的稳定优势标准。这个结果也不能证明两组等效、匿名化更优或化学知识没有作用。

## 与投稿计划的关系

本轮补充的是投稿计划实验二 Q3 的**语义标签匿名化消融**。此前 R1/R2 随机规则实验检验 LLM 规则能否优于指定随机规则分布；本轮进一步检验，规则生成和搜索收益是否依赖模型看到的化学语义标签。这里比较的是两种输入下新生成的 LLM 规则库，不是新增一轮 R1/R2 随机规则比较。

历史提示词未提供具体试剂名称或原始 SMILES，因此匿名化作用于字段、类别、任务等语义标签，保留数值统计、频数和规则空间。它没有消除所有可能的结构线索，不能单独排除预训练记忆。

投稿中可以报告：本批次有标签库全部通过执行契约校验，匿名库有 3 个无效；但在预先定义的整库回退流程中，语义标签未呈现稳定的搜索 AUC 优势。因此，已有随机规则优势不能直接归因为化学语义知识。专家盲写规则、第二数据集和新数据前瞻验证仍是独立待补证据。

## 已冻结并实际执行的设计

- 模型为 OpenRouter `openai/gpt-4o-mini`，同原提示正文、模型设置与规则语法；20 次全新调用组成 10 对，不复用 v1 输出，不修补、不补抽、不重试。
- 每个有效库 5 个策略，规则数 `[2,1,1,1,1]`；均用相同校准预算五选一。无效库整体回退为共同目标基线，不将节省的预算转给其他库。
- BH 有限池 3,955 个候选；每条轨迹初始观测 5 个，再揭示 10 次。校准种子 `202610205000–202610205049`，留出种子 `202610206000–202610206099`。
- gate 原样保留：风险调整增益 ≥0.25、正收益折比例 ≥0.8、平均最终值与 AUC 增益 ≥0、最终值不劣比例 ≥0.55。
- 共同回退基线由校准数据从原三个目标基线中选定，为 `target_acquisition_portfolio`；20 个库的主策略与部署策略在留出前锁定。
- 主比较纳入全部 10 对。有效库使用不应用 gate 的校准五选一赢家；无效库使用共同基线。gate 后比较为次要结果。
- 唯一主比较为 10×100 成对 AUC 差值的平均；10,000 次交叉 bootstrap 共同重采样生成对与共享种子。区间条件于已完成的校准选择；1,000 个格子不是 1,000 个独立样本，10 个生成对也不是 10 个科学任务。

## 生成与留出结果

| 项目 | 有标签 | 匿名 |
|---|---:|---:|
| 生成有效库 | 10/10 | 7/10 |
| 整库无效回退 | 0/10 | 3/10 |
| 校准 gate 接受规则库 | 2/10 | 3/10 |
| 主策略留出平均 AUC | 85.170 | 85.430 |
| gate 后留出平均 AUC | 83.457 | 84.245 |

共同基线留出平均 AUC 为 **82.970**。AUC 是揭示轮次上最佳已观测产率的平均，单位为产率百分点，**不是 ROC AUC**。有效生成数只是本批次的描述；没有额外进行合法率显著性检验。

| 比较 | 平均 AUC 差 | 95% 交叉 bootstrap 区间 |
|---|---:|---|
| 有标签 − 匿名：主比较 | -0.260 | [-1.781, +1.365] |
| 有标签 − 匿名：gate 后（次要） | -0.788 | [-2.537, +0.825] |
| 有标签主策略 − 共同基线（次要） | +2.200 | [+0.353, +4.099] |
| 匿名主策略 − 共同基线（次要） | +2.460 | [+0.932, +4.309] |
| 有标签 gate 后 − 共同基线（次要） | +0.487 | [+0.000, +1.466] |
| 匿名 gate 后 − 共同基线（次要） | +1.275 | [+0.000, +2.846] |

两个主策略相对共同基线的次要 AUC 区间为正，但语义标签主比较区间跨 0；本批次探索性结果不支持“只有保留化学标签才能获得收益”的解释。多项基线比较是次要分析，不能替代唯一主检验或当作多项独立确认性证据。gate 后两组相对基线的区间下界均为 0，反映大量库回退同一基线的结构，也不能写成严格正优势。

主比较的五个连续 20 种子块均值依次为 **-1.051、+1.045、-1.373、+0.018、+0.061**。10 个生成对中，4 对有标签 AUC 较高，6 对较低。

两侧都有效的 7 对，其主 AUC 差均值为 **−1.213**，其中 6 对为负；这是按生成结果形成的子集，**只作描述，不另作确认性区间或推断**。它不能用于宣布匿名化更好。

其他探索性指标（有标签 − 匿名）：主策略最终最佳产率差 **−0.801** 个百分点，top10 命中比例差 **−0.009**（−0.9 个百分点）；gate 后对应 **−0.759** 与 **−0.050**。未为这些指标新增检验。

## 无效库、运行中断与证据保全

无效库为 `pair_00_anonymous`、`pair_02_anonymous`、`pair_07_anonymous`。独立诊断在这 3 库的 21 个条件中定位到 5 个非法条件：4 个使用源任务字段，1 个使用不可执行的角色字段。别名可正确反解；简单 source→target 字段替换也不能使这些条件直接合法。原响应、错误、映射和账单均保留，未挽救其中部分规则。

原运行完成校准与选择锁后，WSL 进程环境中断；精确原因不明。原留出轨迹文件为 0 字节，无持久化留出指标。原目录 401 个文件已整体归档，除 0 字节留出占位文件外的 400 个文件原字节复制到独立恢复目录；原选择锁和所有科学配置保持不变。恢复只重新执行原定 100 个留出种子，调用原冻结分析函数。

恢复使用单独封存、经 8 项离线测试的外部入口，输出目录变化有独立运行来源记录。正式生产冻结前已有 141 项离线测试通过。中断前可能存在未落盘计算，未编造其耗时或完成数。

最终保存 13,200 条逻辑轨迹（沿用校准 4,400＋新执行留出 8,800），按相同执行配置合并运行后保存了 12,150 条轨迹；gzip 事件为 40,500＋81,000 条，完整且无重复缺失。恢复留出用时约 15.72 分钟。本地校准、留出和审计的模型 API 调用均为 0。

## 成本、结论边界与下一步

本轮 20 次调用新增费用 **$0.0218514**；v1 费用 **$0.0125145**，本次匿名化 v1＋v2 累计 **$0.0343659**，低于批准的 $1 上限。v1 的 11 次请求与无效停止证据独立保留，没有并入 v2 样本。

本主指标合并“生成是否合法”和“被选规则效果”，不能直接解释为纯化学知识的因果贡献。只考察一个已知 BH 有限池、一个模型别名和这批新生成库；模型别名也不是不可变后端快照。区间跨 0 不代表等效，较低点估计不证明匿名化优越。相对基线的正收益也可能来自数值统计、规则空间和筛选流程；本轮没有分离这些解释。

按投稿计划，下一步可讨论专家盲写规则或 Suzuki 第二数据集。具体规则提供者、任务方向和新增 API 预算需要用户决定；本轮没有据结果修改提示词、调整 gate、追抽库或启动新的实验。
