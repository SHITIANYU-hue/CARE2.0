# 声子性质训练前后配对诊断：完成

声子目标从未作为 SFT 的目标或来源出现。基座和 epoch-2 QLoRA adapter 使用相同介电性质来源证据、提示、种子和预算。每侧完成 7 次有效生成和 50 条评价轨迹。训练后无反馈第一次生成的非法字段被编译器拒绝；具体允许值反馈后重试成功，失败尝试完整保留。

最清晰的增益来自训练后的初始方案：10 个配对起点中 8 胜、2 负，条件性 bootstrap 区间不跨 0。两轮真实反馈相对训练后初始/无反馈均为 **-7.93471**，区间 [-22.69769, +6.88929]；相对打乱反馈为 **+13.62497**，区间 [+2.59513, +26.07493]。正确反馈比故意打乱反馈好，但本轮最好的做法仍是保留训练后初始方案。

执行审计与这一结论一致：基座三类修订都没有改变 100 轮候选选择；训练后真实反馈改变 99/100 轮，无反馈改变 0/100，打乱反馈改变 100/100。递归更新确实改变了实验决策，但没有超过训练后初始策略。

这是新目标任务证据，不是独立领域证据。训练中使用过相同材料字段和介电来源；1,265 个声子候选中有 112 个与 512 个来源观测具有相同组成字符串，且组成字符串不等于晶体结构身份。没有目标声子值进入来源提示、checkpoint 选择或修订提示。

区间只描述 10 个配对起点，来自一条贪心生成链。该结果是公开数据离线重放，不是新湿实验结果。
