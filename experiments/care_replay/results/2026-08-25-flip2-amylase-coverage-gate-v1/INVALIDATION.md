# FLIP2 Amylase v1 execution invalidation

## Status

This execution is **invalid for confirmatory or efficacy claims**. It is retained
only as an audit of an upstream split-contract failure. None of its numerical
effects should be reported as CARE 2.0 transfer evidence.

## What was frozen correctly

- The public task specification, Opus hypothesis, protocol config, and
  preregistration lock were committed and pushed before the Amylase file was
  downloaded.
- `anthropic/claude-opus-4-8` received no target outcomes and selected the
  frozen `source_additive_mutation_prior` skill.
- The preregistration lock records `raw_dataset_present_at_freeze=false`.

## Why the execution is invalid

The frozen protocol defines the published FLIP2 one-to-many direction:
zero/single-mutation source variants to higher-order target variants. The
downloaded file labels encode the opposite direction.

| Audit | Frozen/public contract | Downloaded rows |
|---|---:|---:|
| Source role | 0 or 1 mutation | 3,218 rows, primarily 2-8 mutations |
| Validation role | low-order source holdout | 644 rows, all higher-order |
| Test role | more than 1 mutation | 488 rows, all single mutants |

The website artifact and immutable Zenodo v3 artifact contain the same 3,706
sequence, target, split-label, and validation-label records. They differ only at
the compressed-file byte level:

- website SHA-256: `68672903e56c9e3c23bd65bb6dde0bb8e31f676a84e3c00df929d539bd48f766`
- Zenodo v3 MD5: `97006840cd899e93fc011202b7d008c2`
- Zenodo v3 SHA-256: `03c42ab34e7ba9e420234d44980ae1215b66f8cfca605d344ebd29140df2b711`

The run therefore evaluated higher-order-to-single transfer, not the
single-to-higher-order hypothesis generated by Opus. The observed deployment
delta (`+0.001728` best-so-far AUC; nominal 95% CI `[0.000062, 0.003394]`) is
scientifically inapplicable to the preregistered question.

## Corrective action

1. Preserve all raw outputs and hashes under this directory as an invalidated
   execution audit.
2. Reject any Amylase file whose labels contradict the published mutation-order
   split before fitting, gate selection, or target replay.
3. Do not repair or reinterpret the split after observing these outcomes.
4. Seek a corrected upstream split or move the next prospective confirmation to
   a previously untouched external family.
