# Unbounded High-Authority Diagnostic

This directory is development evidence, not a reportable suite result. The
first high-authority controller allowed Opus to execute any candidate in the
union menu. ESOL improved by `+0.8143` best-so-far AUC, but Lipophilicity fell
by `-11.3625`: Opus selected source-favored candidates thousands of positions
below the target-only GP default.

The materials run was stopped after this failure mechanism was confirmed, so
its trace is intentionally partial and has no summary. The result motivated the
bounded controller used in `2026-08-16-opus48-bounded-ei-development-v2`, where
Opus retains final authority only inside the target-GP top-five credible set.
