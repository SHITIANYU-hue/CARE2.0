## 2. 重分析要求保留和收缩的结论

本次主分数 `S=(AUC−R)/(O−R)`，R 是同池同预算下完整随机搜索的精确期望，O 是池最优。ΔS=0.10 表示额外取得随机到最优差距的 10%，不是产率提高 10 个百分点。32 个主分母均为正、没有近零预警。单任务按正的共同分母缩放不会改变区间是否跨零，故本次不是一次独立复现。

| 论文主张 | 更新后的写法 |
|---|---|
| 固定规则能改善搜索 | 在四个既有有限池与原预算下，相对各自原 anchor 的 ΔS 为 FreeSolv +0.0287、Lipophilicity +0.0651、BH +0.1281、bandgap +0.1102，原 95% 区间缩放后仍均高于零。保留任务与基线限定；不按原始 AUC 排跨任务大小 |
| LLM 优于随机规则 | 保留 BH 历史库的覆盖匹配主比较；不能推广到 Suzuki、全部新生成库或所有 gate 后部署。BH 覆盖匹配相对 GP-EI 为 +0.0106 [−0.0759,+0.0972]，未证实稳定胜过强 BO |
| 收益来自可迁移化学知识 | 尚未证实。BH 标签优势未成立，Suzuki 三条主比较均跨零。匿名化不是训练污染排除试验；未见优势也不是等效或“化学知识无用” |
| 组成匹配改进 gate | 应改为收益与误判的取舍。等组描述性 ΔS：Always−Never +0.2046 [0.1194,0.2987]，G0−Never +0.1713，G1−Never +0.1156，G1−G0 −0.0557 [−0.1014,−0.0159]；Never 是 target-only GP，不是随机搜索 |
| gate 更安全 | G0 误收 1/1、误拒 3/16；G1 误收 0/1、误拒 10/16。保留这些分母；唯一有害案例被拦下，不能写普遍安全或误收率已可靠估计 |
| 蛋白平均增益几乎由 SPG1 支配 | 在相同组等权下，其绝对贡献份额从源 IQR 的 96.56% 降到新 S 的 15.75%；新描述性正向平均不再几乎完全由该组支配。原 IQR 主分析及分类保留，不能更换为只展示有利尺度 |

同起点补充中，BH 对 GP-EI 点估计变为 −0.0211；其条件分母改变种子权重，且未作区间推断，不能说已证实劣效。它进一步要求保留“相对强 BO 的小优势不稳健”这一限定。存在条件零分母的整体均值按批准规则记 NA，没有删去种子凑平均。

上述结果更适合围绕“区分规则作用、初始化收益与部署筛选，并限定证据范围”组织论文。是否据此改变首投方向由负责人决定；当前没有足够证据把主线改成普遍化学知识优势或新反应发现。

## 3. 哪些缺口现在值得做，哪些先保留

- **可立即开展的后续离线工作：** 完成实际动作和 token 记录的可引用汇总；核查历史源数据／暖启动迁移中协议预算与实际轨迹的差异；整理每项论文主张对应的结果、图表和局限。无需专家、新数据或模型 API。
- **下一项新增实验优先候选：跨模型固定规则／迁移复现。** 它直接补 Q1，目前没有专家和晶泰数据也能设计。建议先形成非 RSI 子方案，与实验一负责人共享模型／版本和重复单位；包含新的独立规则生成，不能靠更多旧库起点替代。任务组合、生成次数、失效处理、主比较、调用及费用上限尚未确定，必须先交用户决定。
- **次级可选：BH 源信息有／无的 Suzuki 成对消融。** 它能识别源证据增量，但不能补上跨模型普适性、专家对照或未见数据。不能直接把当前有源组与未来新无源组混配成同期成对设计；需单独方案和生成预算。
- **暂不优先：继续增加同池随机种子或为 G1 调参。** 当前缺口主要是独立模型／生成库／数据面板，不是同池精度。若开发 gate v2，这 23 条已揭晓路线只可作开发数据，需另立独立验证；刻意挑选有害路线的压力测试不能用于估计自然误收频率。
- **等待资源：专家、新数据、湿实验。** 保留未完成标记。若考虑公开替代数据，先决定是否启动资格检索；发表晚本身不能证明训练不可见，需核实模型版本、首次数据公开和先固定后揭晓安排。

## 4. 推荐下一步：完成实际动作、成本与历史迁移的离线审计

这是原计划“花 token 之前”的剩余工作。AUC 已完成，不应再重复一轮 AUC 盘点；本步把未闭合的归档证据转成能引用、能核预算的表格。

建议交付四项：

1. **实际决策表。** 分协议区分模型真正调用、gate fallback、模型提议改变 GP 首选、最终实际执行改变；保留各自分母。已有受限试点为 6 次真实调用、0 次改变 GP 首选；另 54 轮 fallback 不能当成模型同意 GP。高权限协议另报，不能把这 0/6 推广到全部控制器。
2. **用量与失败表。** 对应成功／失败／未尝试记录，列 prompt、completion、总 token、已知账单费用及未知项。旧盘点三协议完成量为 11/330、1/330、6/180；成功轨迹记录 token 分别 1,674,083、113,103、99,243。它们是历史记录量，不是完整实际收费或新预算预测。最近 BH／Suzuki 的按库生成与在线逐轮决策分开核算。
3. **历史迁移可比性缺口表。** 追踪“协议初始化 5＋后续 10、部分实际初始化 2”的来源，核对原代码版本、候选池与轨迹。只读重建事实；若必须改纳入范围、按实际预算重新定义比较或补跑，形成可审阅选项后停下。不能擅自修成统一预算再并入本次冻结 32 项。
4. **论文证据清单。** 每条主张链接数据与图，标明比较对象、独立单位、区间层级、是否回顾性，以及未覆盖的问题。原四任务、BH／Suzuki、蛋白继续分面板，不生成全记录总胜率。

验收：每个比例可追溯分子分母，每项用量明确覆盖成功／失败范围，每个缺口明确“可复核／缺文件／需改方案”，并把无法识别的费用保留未知；不把 token 按未经批准的现价换算为历史账单。此步预计模型 API 0、模型费用 $0；是建议的下一项工作，本轮未启动该完整审计。

16 条旧失败已查明：6 条费用上限、3 条余额不足、2 条密钥失效、4 条人工中断、1 条输出校验失败。修正原计划“16 次网络中断”措辞。补齐这 16 条也不等于完成三套在线协议；尤其校验失败不能直接当传输失败重试。是否续跑、冻结模型是否可恢复及失败终态处理均需另行批准。
