覆盖匹配后，LLM 仍优于多数抽样，但有随机规则超过它。不同执行配置的数量明显少于抽样数量，因此同时保留两种权重。执行配置去重保留全部规则和数值参数，只去掉标识及解释文本；它不合并所有在 BH 上具有相同激活范围的配置。平局依据归档精度下的 AUC 均值。

这项排名是计划所需的补充描述，**不等同于原先每库五选一的主比较，不是整个规则语法空间的排名，也不是新的确认性检验**。此前五选一主分析的结论仍以 [覆盖匹配报告](BH_COVERAGE_MATCHED_RULE_CONTROLS_V1.md) 为准：对所抽样随机库的主要比较为正，但尚无稳定优于所选强 GP 基线的证据，亦未完成跨任务或化学因果验证。

## 历史盘点：匿名化范围（以下决定已完成）

历史实际发送的 BH payload **没有具体试剂名称或原始 SMILES**。它包含分子量 / TPSA 分箱、碱 / 卤素类别、BH / Suzuki 身份、频数及源任务统计。因此只把底层试剂名称改为代号，模型实际看到的输入基本不变，无法检验计划中的问题。

待确认方案：字段、类别、任务及对应标签一起编码，保留统计数值、优化方向和规则空间；同一模型与设置下重新生成有标签 / 匿名化成对库。预览例：`ligand_mw_bin = mw_high` → `F26 = V09`。

预览已核对 119 处可逆标签变换、204 个数值叶子保留。**它仍是审阅草稿，未完整处理自由文本及系统消息，不可直接作为匿名化 API 请求。** 保留频数和结构也意味着它不能证明彻底排除了化学线索或训练数据污染。

历史记录只有模型别名 `openai/gpt-4o-mini`，没有不可变快照；旧 prompt 要求 8 条策略、解析 8 条、最后规范化为 5 条。新设计须在生成前写清五条有效策略的格式契约、无效返回 / 重试规则及代号映射方式；不能按结果反复生成。当前生成器还可能注入知识库卡片，须审计最终消息以防重新引入标签或旧结果。

待用户确认的两项当前问题：

1. 是否采用上述语义标签匿名化与新生成成对设计。
2. 可用 API 服务、具体模型版本、重复对数和费用上限。10 对仅是供选择的规模示例，未选定或执行。

一次生成一个规则库，`n` 对需要 `2n` 次逻辑调用。旧单次记录为输入 3,588、输出 1,698，共 5,286 token；据此作算术量级参照，10 对约 105,720 token。**这不是预测、报价或上限**；新提示词、模型、返回长度和重试会改变消耗。当前 helper 最多 4 次 HTTP 尝试，正式预算必须包含失败与重试。尚未选服务及计费模型，未估美元费用，未使用密钥。

用户确认后才能完善并冻结正式协议、完整提示词、新校准 / 留出种子。规则解码、执行校验、五选一校准、留出回放与审计可本地完成，重新生成规则需要 API。

## 归档盘点中发现的证据边界

- 计划所说的“16 条网络中断搜索”，实为 6 条费用上限、3 条余额不足、2 条密钥失效、4 条人工中断和 1 条模型输出校验失败。最后一种按原协议是终止性失败，不能自动按网络故障补跑。相关三个协议仅完成 11/330、1/330、6/180；修复 16 条不等于完成整个协议。此项与在线模型实验相关，仅做盘点，未扩大当前非 RSI 工作范围。
- 高权限 v1 的 11 条完成搜索平均记录 152,189 token；受 gate 保护的 6 条平均 16,540.5 token。后者实际 6 次模型决策中 0 次改变 GP 首选，其余 54 轮是 fallback。两类控制器不能合并为统一成本；失败调用消耗未必完整记录。
- 旧随机搜索 50 个起点与部分 headline 500 个起点不同。候选池、初始化、预算、目标变换核对前，不能直接拼成归一化分母；本轮未报告跨任务归一化效应或等效结论。
- Amylase 归档含 `INVALIDATION.md`：实际 split 方向与冻结的单突变到高阶突变方向相反，该执行不得作为效力或确认性证据。本轮已更正 readiness 文档的过时状态，未改 split 或重新解释其效应。
