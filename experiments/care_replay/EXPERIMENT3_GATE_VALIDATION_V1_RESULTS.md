# 实验三：23 条迁移的校准与留出结果

完成日期：2026-10-20。**正式冻结后执行完毕，30 项离线测试通过，全部轨迹审计通过；模型 API 0 次、费用 $0。** 本报告保留全部预定路线，无排除、无追加种子、无重抽、无阈值调整。

## 主要结论

本面板不支持“组成匹配 gate 降低误拒”的预期。原 gate（G0）误拒 3/16，组成匹配 gate（G1，含不支持时回退）误拒 10/16；G1 未救回任何一条原 G0 明确有益却被拒绝的路线。G1−G0 的全路线平均 AUC 差为 **−0.4493 个源 IQR，95% 依赖簇 bootstrap 区间 [−1.2697, −0.0282]**。这些是固定面板的估计，不能推广为所有蛋白任务的保证。

G1 拒绝了唯一的明确有害路线 PHOT 高阶外推，G0 接受了它。但有害类别只有 **1 条路线、1 个簇**，无法据此声称普遍降低误收或达到安全保证。

## 已批准且实际执行的流程

- 23 条冻结路线，来自 13 个候选依赖簇；9 条普通哈希域、4 条受控组成偏移、10 条阶数外推。均为同一测量景观内的分布迁移，不是 23 次跨蛋白迁移或 23 个独立家族。
- 每路线源拟合 1,024 条；源校准伪目标池每 gate 128 条、100 个配对种子；正式目标每路线 200 个新配对种子，每轨迹 3 次初始化＋12 次揭示。
- 用户批准的计分换算：仅用本路线源拟合集确定中位数、IQR，执行值＝100×(原值−源中位数)/源 IQR；无裁剪、无目标统计量。ProteinGym 的处理后 DMS_score 已统一为越大越好。
- 固定加性迁移算子、GP 参数和 0.5→0.1 权重衰减保持；原 gate 仍为配对 AUC 正态 95% CI 下界 >0。G0/G1 使用相同预算，未根据结果调整匹配规则。
- 全部 gate 及 3,600 个校准配对记录先锁定，之后才启动正式目标留出。10 条外推路线均不支持预定组成匹配，G1 固定回退 Never；未把闲置校准预算分配给其他路线。
- 实际运行：3,600 校准配对＋4,600 留出配对＝16,400 条轨迹，共 246,000 次模拟观测。四臂共享两套基础轨迹；这些是已有数据回放，不是新增湿实验测量。

## 主分类结果（δ＝0.02 源 IQR）

| 指标 | G0 原 gate | G1 组成匹配 gate |
|---|---:|---:|
| 接受路线 | 15/23 | 8/23 |
| 误拒：拒绝的明确有益路线 / 全部明确有益路线 | 3/16（18.75%） | 10/16（62.50%） |
| 误收：接受的明确有害路线 / 全部明确有害路线 | 1/1 | 0/1 |

留出真值：**明确有益 16、明确有害 1、实际近零 0、不确定 6**。误拒率增加 43.75 个百分点；按依赖簇重采样的差值区间为 +23.08 至 +66.67 个百分点。

误收率的 bootstrap 在抽到唯一有害簇时差值恒为 −1；10,000 次重采样仅 6,427 次有非零分母，其余无定义。机器输出保留该退化区间，但它不提供有意义的总体误收不确定性证据，不能把 0/1 解释为零风险。

单位为平均 best-so-far AUC 差 / 源拟合集 IQR。区间为对 13 个候选依赖簇整簇重采样 10,000 次的 percentile 95% 区间，主估计按路线等权；未把 200 个种子当作 200 个独立数据集。

|---|---:|
| 总迁移 − 从不迁移 | +14.0436 [+0.1639, +43.2988] |
| G0 − 从不迁移 | +13.9633 [+0.0911, +43.2635] |
| G1 − 从不迁移 | +13.5140 [+0.0277, +41.9816] |
| G0 − 总迁移 | -0.0803 [-0.1666, -0.0099] |

## 哪些结论得到或未得到支持

1. **原 gate 确实存在误拒。** DLG4 阶数外推、GCN4 受控偏移、RASK 阶数外推三条在留出上明确有益，却被 G0 拒绝。它们是投稿计划实验三所需的新面板误拒证据。
2. **本次匹配方案没有修复误拒。** 13 条有匹配支持的路线中有 10 条明确有益，G0 误拒 1 条、G1 误拒 4 条；因此总体劣势也不能全部归因于那 10 条不支持路线。
3. **共同支持不足不等于迁移无效。** 10 条不支持匹配的外推路线中，6 条明确有益、1 条明确有害、3 条不确定。固定回退避免了一个有害案例，也放弃了六个有益案例。
4. **降低误收的总体证据不足。** 有害分母只有 1，不能做非劣效、等效或普遍安全声明。预先指定的 δ=0.05 下没有明确有害路线，误收率必须记 NA。
5. **本实验没有检验 LLM 知识优势。** 全程使用固定源数据加性算子；BH/Suzuki 的随机规则和匿名化结论不能由这里替代。

## 与投稿计划的对应及下一步边界

本轮完成了实验三预定的 ≥20 条迁移回放、原／匹配 gate、总使用／从不使用四臂，以及误拒、误收、决策损失的完整结果。可在论文中报告“原接受测试会误拒；这套组成匹配与不支持回退方案未改善效果”。不能写成“已证明修正 gate 更优”，也不能将本轮公共数据回放称为实验四的新非公开数据前瞻验证。

23 条路线共有 13 个候选依赖簇。公开同源筛查未发现预设近同源警报，但这不是远缘家族完全独立的证明；同一蛋白两种划分存在跨路线角色重叠，按簇统计、单路线访问和固定决策处理。分组条件下的区间不能替代新增独立家族验证。

**当前没有启动任何方案变更或新 API 调用。** 若继续改进 gate，下一步应先设计新版本，并明确这 23 条路线已成为开发证据，另行冻结新验证面板。是否改变不支持时的回退规则、引入目标校准、改归一化或招募更多有害迁移，均需用户另行决定；不能在本轮结果上调参后继续称作同一确认实验。
