## 为什么另起 v2

v1 在第 11 次累计请求遇到真实无效输出：匿名库使用了源任务字段 F19，而目标目录要求其对应目标字段 F01。提示词已列出目录约束和源到目标映射，核查未发现代码或别名错误。按 v1 已批准规则终止，留下 10 个有效库／5 对，累计费用 $0.0125145，尚未查看本轮 AUC。

v2 保留 v1 原始失败、有效输出与账本，不将其中有效库拼入新实验。保留原提示词可避免针对这次匿名组错误额外修改指令。新方案不保证模型输出必然有效，而是预先定义所有合法性结果如何进入评估。

## 三种状态及明确处理

| 状态 | 确定性条件 | 处理 |
|---|---|---|
| VALID | 来源、费用和冻结输入通过检查；正常完成，整份输出通过 JSON、数量、字段、值和参数验证 | 保存完整 5 策略库；按原流程五选一 |
| INVALID_ANCHOR_FALLBACK | 已收到账单和来源明确的模型完成，但整库契约不符；包括非法 JSON、重复键、非有限数、非法字段／值、错误数量／参数、超长文本 | 保存整份原响应与错误；整库回退；消耗本槽，继续下一槽 |
| INVALID_ANCHOR_FALLBACK | 费用和来源明确的内容拒绝、空输出、length 截断、content_filter 或返回工具调用，未形成要求的库 | 同样整库回退，不再次请求，不实际调用工具 |
| HALT | 网络或 HTTP 错误、账单不明、BYOK、预算问题、来源／冻结哈希不符、材料损坏、坏响应外壳、未知完成原因或验证器内部异常 | 停止运行，保留预留和证据；不能伪装成无效规则回退 |

来源、账单、输入和响应外壳检查先于内容判定。服务端 HTTP 层拒绝若没有正常、已对账的模型完成，属于 HALT。两组使用相同判定，不能人工按“化学机理不合理”或“创新性不足”拒绝规则。

一条规则非法就整库无效。不得将 F19 自动换成 F01、保留其他合法策略、裁剪、补全、重抽或给其他库追加预算。20 槽必须全部有已对账的 VALID 或 INVALID_ANCHOR_FALLBACK 结果，才可进入正式评估；存在 HALT 或未请求槽则不计算主结果。请求不自动重试；基础设施中断后的恢复须先核查证据，不能重复产生模型返回。

## 共同回退基线与主比较

只在 50 个校准种子上，从原有 `gp_ucb`、`mixed_kernel_gp_ei`、`target_acquisition_portfolio` 三个目标基线按现有 `mean(final_best)+mean(AUC)` 及原取整／平局规则选出一个共同 anchor。选择不依赖任何生成库或留出表现，所有库共用，在留出前锁定；即使 20 库都无效，也能只用基线校准得到它。

有效库的主策略为原校准流程选出的 ungated 五选一赢家；无效库的主策略为共同 anchor。Gate 后的部署策略作为次要结果：有效库沿用原 gate，无效库仍为 anchor。

对第 p 对、共同留出种子 s，记：

`D[p,s] = AUC(有标签主策略, s) − AUC(匿名主策略, s)`

主效应为完整 10×100 差值矩阵的等权平均，只设一个主比较。两边无效时该对所有差值均为 0；一边无效时，另一边赢家与同一个 anchor 比较。无效是预定义策略结果，基础设施缺失不能按此补值。

保持原 10,000 次交叉 bootstrap：独立重采样配对行与共同种子列，两臂始终成对，报告一个 95% 区间。沿用描述性稳定标记：主区间下界大于 0 且五个连续 20-seed 块的平均差都大于 0。五块不是额外独立检验；10×100 个格子不是 1,000 个独立样本，区间不包含校准选择的再次抽样。

报告同时给出：

- 两臂有效／无效库数、错误类别、单边无效和双边无效配对数、gate 接受数。
- 全部 10 对的主 AUC、逐对差值、五块描述、Gate 后 AUC，以及两臂相对共同 anchor 的效果。
- 双边有效配对的原始 AUC 差，仅作描述，注明实际配对数；不另作确认性显著性结论，不把该子集推广到所有生成。子集为空时标记不可用。
- 最终最佳值与 top10 命中率为探索性指标。

若全部库无效，主差和区间按构造为 0，必须同时报告“没有有效生成库”；不能解释为语义无贡献、等效或高精度知识估计。即使区间包含 0，也不能声称两种输入等效。
