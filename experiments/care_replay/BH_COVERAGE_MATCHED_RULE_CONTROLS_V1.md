# BH 覆盖比例匹配随机规则对照 v1

本轮检验：限制随机规则与原 LLM 模板覆盖相近数量的候选后，历史冻结 LLM 五策略库的留出 AUC 优势是否仍满足预定稳定性标准。沿用已知 BH 池的离线回放，模型 API 调用为零；原 pilot 与扩大实验全部保留。

## 回放前固定的协议

配置 `configs/bh_coverage_matched_rule_controls_v1.json`；本地冻结文件 `preregistrations/bh_coverage_matched_rule_controls_v1.lock.json`。冻结涵盖配置、所有脚本、数据、完整抽样库、执行别名与覆盖条件池的 SHA-256。这是本地运行前冻结，不是外部注册。

- LLM 沿用原五策略记录。R1/R2 各抽 100 个库，每库五个候选，按五个原模板各抽一个策略；各 500 次策略抽样、600 条原子规则。每库独立五选一，不跨库选最佳、不额外生成候补策略。
- R1 保留字段；R2 在原类型/基数组内采用整个策略一致的单射字段映射。两者保留规则顺序、条件数、字段复用、绝对权重、置信度及所有执行超参数。
- 覆盖条件：对每条有序规则，其命中数除以全池 3,955 个候选，与对应 LLM 规则之差的绝对值不超过 0.005（0.5 个百分点，最多相差 19 个候选）。同时要求完整联合激活 bitmask 直方图的每个 cell 比例之差也不超过 0.005；单规则时该条件等价于覆盖匹配。
- 条件只读取 catalog 白名单内的公开字段，不读取或散列 metadata 中的 `yield_value` 等隐藏标签。符号不参与覆盖判断。
- 穷举原随机零假设的字段/值条件配置，筛出满足覆盖条件的有限集合，再有放回均匀抽样，每条规则独立抽正负号。同一类型组的字段基数必须一致，否则报错；因此筛出的配置等概率，得到原随机零假设在覆盖条件下的条件分布。没有基于校准或留出表现拒绝、补抽、调节容差。
- 允许身份映射、重复策略与恰好重现原 LLM 策略。只复用精确相同执行输入的计算，保留全部逻辑候选、库成员和原 tie-break。

0.005 容差在任何新回放前确定。公共元数据预检显示，少量缺失组合使三类 aryl halide 的覆盖仅差 1/3,955；精确数量匹配会因此锁死原类别。0.005 仍严格排除约 9% 与 91%、25% 与 75% 的不匹配。联合条件进一步约束多规则的重叠结构，不要求匹配候选身份或结果分布。

## 种子、预算与 gate

规则抽样种子 `2026101804`；新校准起点 `202610185000–202610185049`（50 个），新留出起点 `202610186000–202610186099`（100 个）。排除原 smoke、pilot 与扩大实验全部起点。每条轨迹五个初始候选、十次新揭晓；所有库及三个目标基线共用每个起点。

共 1,008 个逻辑模式、151,200 条逻辑轨迹，随机库筛选预算仍为每库五选一。沿用 canonical selector 和全部 gate：composite 风险调整增益至少 0.25，正增益五折比例至少 0.8，final non-loss 比例至少 0.55，final 与 AUC 均差非负。共同目标基线由新校准集按原规则选择。完成全部校准后写选择锁，才启动留出；未门控校准赢家和 gate 部署模式均在留出前固定。

## 预定分析与解释范围

主终点为 LLM 未门控校准赢家减各随机库未门控校准赢家的留出 AUC，库与起点等权。AUC 是十轮 best-so-far 均值，单位为产率百分点。采用固定种子 `2026101805` 的 10,000 次交叉 bootstrap，分别重抽随机库、共享重抽留出起点；两族各 97.5% percentile 区间，对两项主比较做 Bonferroni 近似 familywise 95% 控制。

稳定性判据保持不变：R1/R2 主区间下界均严格为正，且按种子顺序划分的五个连续二十起点块，两族全部块均差均严格为正。gate 后部署比较为探索性次终点，报告未调整 95% 区间。final-best 和 top-10 只作描述。不根据本轮结果修改标准。

公共预检可行空间（含符号、按模板执行参数区分）：R1 的五模板分别有 12/6/2/2/2 种，共 24 种；R2 为 36/18/4/2/2，共 62 种，按实际公开激活等价进一步只有 42 种。三个数值模板在匹配后主要退化为符号检验；R2 的 base MW 与 base TPSA 字段可换名但激活一致。因此这是一项更严格、也更窄的条件随机化检验，500 次抽样不等于 500 种新策略。

结论条件于同一 BH 池、历史 LLM 库和本次冻结校准选择。区间不包括重新校准或重新生成 LLM 库的不确定性。不能外推到新任务、所有随机规则、无预训练污染或因果化学知识贡献；与前一版使用不同种子，两个增益之差不能单独归因于覆盖匹配。

## 复现与审计

使用单线程 BLAS、六个进程。运行入口是 `scripts/run_matched_random_rule_controls.py`，须传本配置和本冻结锁。仅创建新的运行目录；源码或配置变化需新版本冻结。冻结脚本为 `scripts/freeze_matched_rule_protocol.py`，不会执行优化回放。

独立审计 `scripts/audit_matched_rule_run.py` 从记录的初始候选和逐轮揭晓重建所有指标、校准选择和汇总，同时重建覆盖条件池与抽样库。`scripts/analyze_matched_rule_stability.py` 使用已锁定赢家，拒绝缺失单元及协议/源码哈希变化。socket 连接在生成与各回放 worker 中禁用；本地数据缺失即失败。归档保留源码、输入、配置、轨迹、指标、统计结果、负结果与报告。

## 完成结果

正式运行目录：`results/2026-10-19-bh-coverage-matched-rule-controls-v1`。配置与 112 个脚本已在回放前冻结。119 项测试、155 个子测试通过。

独立公共元数据审计：1,000 次随机策略抽样全部保持结构、参数、字段映射与覆盖约束，最大逐规则和联合 cell 覆盖偏差均为 2/3,955（0.05057 个百分点）。R1 实际抽到 24 种精确执行策略，R2 为 60 种；两族与 LLM 合并为 61 种精确执行策略、41 种公开激活等价策略。包含任一原 LLM 精确策略的库分别为 87/100 和 81/100；headline 精确身份分别为 6/100 和 3/100。身份与重复样本全部保留，不参与筛选或删样本。

本轮 50 个校准起点选择的共同基线为 mixed-kernel GP-EI。LLM 的未门控赢家和 gate 部署策略均为 `high_mw_ligand_effect`；R1/R2 分别有 60/100、67/100 个库通过原 gate。选择锁写于 UTC 2026-10-19 04:03:13，随后才启动留出。与上一版的 GP-UCB 锚点不同是原选择器在新校准种子上的结果，阈值没有改变。

本轮达到预设主分析稳定性标准：LLM 在覆盖匹配后的 R1/R2 随机库对照中保持正的平均留出 AUC 优势。两族调整区间下界均大于零，五个预定连续二十起点块的均差也全部为正。

运行耗时 29.4 分钟，完成 151,200 个逻辑评估单元，精确复用后实际执行 9,600 条轨迹及 96,000 次新揭晓。模型 API 调用为零。

### 主终点：固定校准赢家的留出 AUC

差值为 LLM 减随机库，单位为产率百分点。两族各 97.5% 交叉 bootstrap 区间，对两项主比较作 Bonferroni 近似 familywise 95% 控制；胜平负按每库全部 100 个留出起点的均差计算。

| 对照 | 平均 ΔAUC | 调整区间 | LLM 胜 / 平 / 负的库数 |
| --- | ---: | --- | --- |
| R1 | +2.5348 | [+0.7759, +4.2982] | 83 / 6 / 11 |
| R2 | +2.3772 | [+0.7162, +4.0014] | 85 / 10 / 5 |

R1 五块均差依次为 +4.2532、+3.7705、+2.5535、+1.3799、+0.7167。
R2 五块均差依次为 +3.8719、+3.7196、+2.4168、+1.2866、+0.5913。

平均优势不代表击败每个随机库：本轮有 11 个 R1 库和 5 个 R2 库的固定校准赢家在留出平均 AUC 上更好。独立核查发现，这 16 个负库均采用同一激活模式的符号翻转变体：ligand 权重从 +0.8 改为 −0.8、base 保持 +0.6，平均领先 LLM 0.105658 AUC。R1 的 6 个平局均为精确相同执行策略；R2 的 10 个平局包含 3 个精确相同策略和 7 个激活、权重、参数相同的字段别名。不能据此宣称原 LLM 的每个符号方向最优，也不得用本轮留出重新选择。

### gate 部署与目标基线

| 部署后比较 | 平均 ΔAUC | 探索性、未调整 95% 区间 |
| --- | ---: | --- |
| LLM − R1 | +1.3712 | [-0.1229, +2.8167] |
| LLM − R2 | +1.4173 | [+0.0144, +2.7914] |

R1 部署区间跨零，R2 下界仅略高于零；两族部署差的第五块也分别为 −0.0956、−0.0789。因此不能把主终点的稳定平均优势扩展成两族 gate 后部署均稳定获益。

相对本轮校准选出的 mixed-kernel GP-EI，LLM 的 ΔAUC 仅为 +0.2372，描述性配对 normal 95% 区间 [-1.6937, +2.1681]；final-best 为 −0.2159，区间 [-2.1396, +1.7078]。本轮没有提供稳定超过这个目标基线的证据。相对随机库的 final-best 均差 R1 +0.9421、R2 +0.9548 仅作描述，不能据此宣称最终产率显著提高。

### 可以写入论文的结论

“在已知 BH 候选池和固定五选一校准流程下，历史 LLM 规则库相对于逐规则覆盖及联合激活比例匹配的 R1/R2 随机库，仍表现出正的平均留出 AUC 优势，且通过预先固定的区间与起点块稳定性检查。”

这支持优势在几乎相同覆盖比例下仍存在，不能单独归因于宽覆盖与窄覆盖的差异。但不支持 LLM 在每个随机库、每个起点、gate 部署或强 BO 基线上都获益，也不证明新任务泛化或因果化学知识贡献。上一版与本版种子、校准选择和零假设不同，跨版本增益之差不能解释成覆盖匹配的因果效应。
